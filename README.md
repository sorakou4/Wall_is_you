Wall Is You s’agit d’un jeu de labyrinthe où un aventurier doit se déplacer dans un donjon rempli de salles orientées, de dragons, de bonus et de trésors. Le joueur peut pivoter les salles, placer des trésors, demander un indice (si il ne trouve pas de solution) et valider un chemin que l’aventurier va suivre.
Le but est simple: tuer tous les dragons sans mourir.
